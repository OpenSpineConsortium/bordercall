## Traps

- Run the suites from the repository's root with `-t .` for the packages (`python -m unittest discover -s morphometry/tests -t .`), tests/ as `discover -s tests`, and archive/tests from inside archive/.
- scanimport's and combinations' suites need pydicom and PyMC; without them they fail with import errors that are not the code's.
- The stamp hashes every .py file of morphometry/ and scanimport/, docstrings included: finish the wording before a run starts, or the run is measured again.
- anatomy.build takes the neighbours' voxel indices as its sixth argument (measure.neighbours_of); a caller that leaves them out gets the column-line frame with the flag `axis`. measure.measure_volume and maskedge.edge.vertebrae pass them; morphoview and morphobench build through those.
- C2 keeps the column's line (its lower plate alone faces a neighbour and lies 35 degrees off that line at 0004), and so does any level whose axis lies over 25 degrees off the line (anatomy.AXIS_TURN_MAX_DEG) or whose turned frame loses the canal; the flag rows say which.
- A container restart kills a run; the rows already written stay, and the run resumes. A `pkill -f` whose pattern is in its own command line kills the shell that runs it.
- The 14 older rows in /mnt/project-files/gold3-ct/morphometry/rows/ and run229-partial/ are from code before the fixes and are not to be used.
- A CT read for a test is read only on the owner's word with its size first, kept in a scratch folder off the project's files, and deleted by its own path afterwards.
