Words used on this page
the engine
bordercall's morphometry engine. It measures each vertebra's mask, and its values are the truth every arm is scored against.
spread
the network's own estimate of how far off a value may be, calibrated so 68 percent of true values fall within one spread.
the oracle
the crop frame used in training, a line through the neighbouring vertebrae's mask centres. A patient has no masks, so it is not there at test time.
three-body field
a view that shows three vertebrae, as a fluoroscopy shot does. Naming is scored as the share of such fields with every body named right.
rib class
how many rib-bearing vertebrae a spine has (eleven, twelve or thirteen). The anomaly spines are scored by it.
shape model (PDM)
a mean vertebra plus a few ways it varies, fit on the real masks. Its weights are the "shape numbers" a latent head gives.
naming rule
the model that reads the measurements (or shape numbers) along the spine and gives each body its name. "Exact" means it sums over every possible run of names.
flow kind
one Metaflow flow held to one frozen pre-registration; flows/launch.py starts it by that name.
launcher run
one run of a flow kind started by flows/launch.py. In an array there is one per trial.
afterany
the Slurm rule that starts a job once the jobs before it have ended, passed or failed.
pre-registration
the written rules and bars, hashed before the first job; a later change is a dated line beside it.
